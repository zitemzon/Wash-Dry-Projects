# Wash-Dry-Projects

## laundry-layout-planner.html — ผังร้านสะดวกซัก 2D

โปรแกรมวางผังเครื่องซัก/อบผ้าแบบ 2 มิติ คำนวณตามขนาดจริง (หน่วย mm) ไฟล์เดียว ไม่ต้องติดตั้ง

- กำหนดขนาดร้าน (กว้าง × ลึก, m) และโซนพื้นที่ภายในร้าน (กว้าง × ยาว) พร้อมพื้นที่ m²
- คลังเครื่อง Speed Queen / Samsung Commercial พร้อมขนาด W×D×H และแหล่งข้อมูล (Spec sheet / ตัวแทน / ค่าประมาณ)
- เพิ่มเครื่องซัก เครื่องอบ Stack เครื่องหยอดเหรียญ/ชำระเงิน เฟอร์นิเจอร์ และขนาดกำหนดเองได้ ตั้งชื่อได้ ทีละหลายเครื่อง เรียงแถวพร้อมระยะห่าง
- เส้นกริด ไม้บรรทัด (m) Snap ดูดติดขอบ ระยะห่างจากผนังและเครื่องข้างเคียง เครื่องมือวัดระยะ
- พื้นที่ว่างหน้าเครื่อง (clearance) และการแจ้งเตือนเครื่องทับกัน ล้นขอบ หรือหน้าเครื่องถูกบัง
- มาร์คจุดกล้องวงจรปิด CCTV พร้อมมุมมอง FOV / ระยะ / ทิศทาง
- สรุปจำนวนแยกประเภท แยกรุ่น จำนวนถังบริการ พื้นที่โซน และ % พื้นที่ใช้งาน
- บันทึกอัตโนมัติในเบราว์เซอร์ ส่งออก/นำเข้า JSON และสร้างภาพ PNG

> ขนาดเครื่องในคลังเป็นค่าอ้างอิง ควรยืนยัน spec ของรุ่นที่สั่งจริงก่อนติดตั้ง
